> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
>
> Для работы zapret необходим WinDivert - инструмент перехвата и фильтрации сетевого трафика. Антивирус может отреагировать на него, поскольку такой инструмент способен использоваться как безопасными, так и вредоносными программами. Сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы относят файлы WinDivert к инструментам повышенного риска или хакерским утилитам, удаляя их и помещая в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение рекомендуется при аккуратной настройке, но если вы не уверены в своих действиях, отключите обнаружение PUA.

## ⚙️Использование

1. Включите безопасный DNS (Secure DNS).
   * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика услуг DNS. Выберите любого поставщика, кроме варианта "Поставщик по умолчанию".
   * В Firefox включите "DNS через HTTPS", установите режим "Персональный", откройте пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках ОС. Инструкция доступна [здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется этот вариант.
   * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Откройте [страницу последнего релиза](https://github.com/Rapidsalawning/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar.

3. Откройте свойства архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот шаг можно не выполнять.

4. Распакуйте архив в путь, в котором нет кириллицы и специальных символов.

5. Запустите нужный скрипт:
   * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
   * Для установки стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) предназначен для установки автозапуска и выполнения других операций:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, которые используют UDP и TCP на портах выше 1023.  
  **После смены режима стратегию нужно перезапустить.**  
  Текущее состояние включения или выключения указано в скобках.
  - **`IPSet Filter`** переключает обработку сервисов, перечисленных в `ipset-all.txt`.  
  Это пригодится при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках отображается текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP проверяется на наличие в списке
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** включает или выключает автоматический поиск обновлений.
  - **`Replace active fakes`** меняет текущий используемый фейк на другой файл из каталога `bin`.
  - **`Update IPSet List`** заменяет `ipset-all.txt` актуальной версией из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространённые вопросы и проблемы

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe, выполняющий обход.  
Если этого не произошло, обратитесь к [#522](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - От имени администратора откройте текстовый файл `hosts` в созданной папке.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение. Если результат не изменился, убедитесь, что hosts действительно сохранился.

#### Результат не гарантируется. При отсутствии эффекта используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Rapidsalawning/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Стратегия иногда действует некоторое время, а затем перестаёт помогать после обнаружения.
> В репозитории собрано много разных вариантов обхода. Если готовые стратегии не подходят, создайте новую на основе одной из них, изменив параметры. Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок.

- Убедитесь, что нужный ресурс указан в списке доменов или IP-адресов.

- Проверьте другие варианты, включая **`ALT`**, **`FAKE`** и прочие стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните ресурсы и данные, добавленные вами вручную.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Откройте `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, а в конце подтвердите действие клавишей Y.
- Удалите старый каталог zapret.
- Скачайте последнюю версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/Rapidsalawning/zapret-discord-youtube/releases).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы.
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если очередная стратегия не работает, закройте программу через значок замка в панели задач и попробуйте следующую.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть ресурсы, которые вы не собирались обходить.

### Античит обнаруживает WinDivert

- Воспользуйтесь инструкцией https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Узнайте имя службы в командной строке Windows. Откройте Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если выбранная раньше работала.
- См. также [#251](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Через `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, помогла ли очистка кэша в приложении Discord.
- Откройте Discord в браузере по адресу https://discord.com/app. Если браузерная версия работает, временно используйте её.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/Rapidsalawning/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Попробуйте следующий общий порядок:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если это не помогло, дополнительно включите режим `ipset any`.

Учтите, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Создайте новый вопрос [здесь](https://github.com/Rapidsalawning/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Списки обхода можно дополнить собственными адресами:
- **`list-general-user.txt`** предназначен для доменов, включая поддомены.
- **`list-exclude-user.txt`** исключает домены из фильтрации. Например, это нужно, если IP-сеть добавлена в `ipset-all.txt`, но конкретный домен внутри неё фильтровать не требуется.
- **`ipset-all.txt`** содержит IP-адреса и подсети.
- **`ipset-exclude-user.txt`** исключает IP-адреса и подсети.
  - Файлы **`*-user.txt`** автоматически создаются при первом запуске `zapret` или `service.bat`.
